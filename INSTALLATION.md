# ResQBlood Installation and Setup Guide

This guide explains how to set up, install, and run **ResQBlood** locally.

---

## 📂 Folders & Files to Exclude (Do Not Send to Your Friend)

Before sharing the project folder (e.g., as a `.zip` file), make sure to **delete or exclude** the following to keep the file size small and protect your API credentials:

1. **`node_modules/`** *(Folder)*
   - Contains all the downloaded NPM dependency packages. It is very large and can be regenerated by running `npm install`.
2. **`dist/`** *(Folder)*
   - Contains the compiled production build. Not needed for development.
3. **`.env`** *(File)*
   - Contains your Supabase URL and private API Keys. Instead of sending this file, your friend should create their own using the instructions below.

---

## 🚀 Setup & Installation Guide (For Your Friend)

Follow these steps to set up ResQBlood on a new computer:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### Step 1: Install Dependencies
Open your terminal inside the project root folder and run:
```bash
npm install
```
This will recreate the `node_modules` folder and install all required libraries.

### Step 2: Configure Environment Variables
1. In the root directory, create a new file named `.env`.
2. Open the file and add your Supabase credentials:
   ```env
   VITE_SUPABASE_URL=YOUR_SUPABASE_URL
   VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
   ```

### Step 3: Database Setup (Supabase)
If you want to set up a fresh database:
1. Create a new project on [Supabase](https://supabase.com/).
2. Go to the **SQL Editor** in your Supabase dashboard.
3. Paste and run the contents of the `supabase_schema.sql` file located in the root of this project. This will set up the required tables, triggers, and Row Level Security (RLS) policies.
4. Enable **Email Auth** in Supabase -> Authentication -> Providers.

### Step 4: Run the Application Locally
To start the local development server, run:
```bash
npm run dev
```
Once started, open your browser and navigate to the local URL shown in your terminal (typically `http://localhost:5173`).
